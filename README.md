# My Midterm Exam Blog

Subjects: Discrete Math, HTML, RDBMS, SQL, Academic Writing, Physics, C++.

## Put it online with GitHub Pages
1. Create a new repository on github.com (e.g. `midterm-blog`), set it to **Public**.
2. Click **Add file → Upload files** and upload everything in this folder (`index.html`, `style.css`, `app.js`, `data/`, `README.md`). Commit.
3. Go to **Settings → Pages**. Under *Branch* choose `main` and `/ (root)`, then **Save**.
4. After about a minute your blog is at `https://YOUR-USERNAME.github.io/midterm-blog/`.

## Add an exam
1. Open your blog and click **+ Add exam**. Fill in subject, title, date, score, questions and answers.
   Use triple backticks for code (SQL / C++ / HTML).
2. It is saved in your browser. To publish it for everyone: open **Publish & backup → Export JSON**.
3. In GitHub, open `data/exams.json` → pencil icon (or upload) → replace with the downloaded file → Commit.

## Images of the exam paper
Upload the photo to an `images/` folder in the repo, then in the form put `images/yourfile.jpg` as the image link.

Delete the sample entry in `data/exams.json` when you add your own.
