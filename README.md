# Midterms Exam Log In & Study Blog

A lightweight, offline-ready web application for recording and tracking midterm exam scores and study notes across 7 subjects:
- **Discrete Math**
- **HTML**
- **RDMS**
- **SQL**
- **Academic Writing**
- **Physics**
- **C++**

## Project Structure
- `index.html` — Login portal and main midterm dashboard structure
- `style.css` — Responsive light-mode styling
- `app.js` — Student login/registration, grade calculator, filtering, and JSON import/export
- `exams.json` — Default midterm exam records (replace with your exported `exams.json` before pushing to GitHub to update your live site)
